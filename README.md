# Online English

Учебное приложение для русскоязычного ребёнка, изучающего английский язык во 2 классе по школьному курсу Spotlight 2 («Английский в фокусе»).

## Цель

Приложение не заменяет учебник и не копирует его упражнения. Оно идёт рядом со школьной программой: закрепляет пройденное, объясняет сложное по-русски, развивает чтение и понимание на слух и предлагает небольшое опережение там, где это помогает ребёнку.

## Учебный маршрут

- Starter / `My Letters!` — буквы небольшими группами, связь «буква → звук → слово», затем короткие гласные и первое чтение;
- `Hello!` — приветствие, имя, простые фразы;
- `My Family` — семья и представление близких;
- Module 1 — `My Home!`;
- Module 2 — `My Birthday!`;
- Module 3 — `My Animals!`;
- Module 4 — `My Toys!`;
- Module 5 — `My Holidays!`.

Последующие модули наполняются оригинальными объяснениями и упражнениями приложения по мере разработки.

## Что есть в MVP

- 9 коротких уроков Starter: группы букв A–D, E–H, I–M, N–R, S–X, Y–Z, короткие гласные, буквосочетания и первое чтение;
- опорные слова для букв, согласованные с вводным блоком Spotlight 2;
- подготовленная офлайн-озвучка с единым британским голосом;
- упражнения на узнавание буквы, слух, чтение и сборку слова;
- школьные темы `Hello!` и `My Family`;
- сохранение прогресса в `localStorage`;
- список ошибок для повторения;
- карта всего курса Spotlight 2 на главной странице;
- адаптивный интерфейс для компьютера и телефона.

## Произношение

Озвучка приложения не зависит от облачного API и не использует случайные голоса браузера. Каждое слово, буква и учебная фраза заранее озвучиваются одним выбранным британским голосом и сохраняются как обычные WAV-файлы в `public/audio/en-gb/`.

Во время урока браузер только воспроизводит эти готовые файлы. Поэтому ребёнок слышит одно и то же произношение на компьютере, телефоне и после публикации приложения. Если нужного файла нет, приложение не подменяет его случайным системным TTS-голосом: отсутствие записи считается ошибкой контента, которую нужно исправить до выпуска урока.

Для подготовки аудиопака используется локальный open-weight TTS Kokoro. Модель запускается только при разработке; интернет и модель не нужны пользователю приложения после того, как WAV-файлы добавлены в репозиторий.

Подготовка окружения на Ubuntu/Codespaces:

```bash
sudo apt-get update
sudo apt-get install -y espeak-ng
python -m pip install -r tools/pronunciation-requirements.txt
```

Список утверждённых реплик находится в `tools/pronunciation_texts.txt`. Генерация:

```bash
python tools/generate_pronunciation.py
```

По умолчанию используется британский женский голос `bf_emma`, скорость `0.92`, формат WAV 24 kHz PCM. Перед добавлением нового урока его новые слова и фразы сначала добавляются в корпус, генерируются и прослушиваются взрослым, и только после проверки считаются готовыми для ребёнка.

Старый маршрут `/api/speech` оставлен только как явно отключённая заглушка и ничего не отправляет во внешние сервисы.

## Принципы обучения

- один короткий урок — одна понятная задача;
- сначала ребёнок видит и слышит материал, затем выполняет упражнения;
- новая тема смешивается с небольшим повторением старого;
- фонетические знаки используются только как подсказка, без требования заучивать транскрипцию;
- интерфейс спокойный: изображения помогают понять материал, но не превращают урок в игру ради игры.

## Запуск

```bash
npm install
npm run dev
```

Откройте порт `3000` в браузере. В GitHub Codespaces порт можно открыть через вкладку **PORTS**.

Для проверки production-сборки:

```bash
npm run build
npm start
```

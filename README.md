# Online English

Учебное приложение для русскоязычного ребёнка, изучающего английский язык во 2 классе.

## Цель

Помочь ребёнку научиться читать простые английские слова, понимать базовые фразы и закреплять школьную программу через короткие уроки, визуальные примеры, озвучивание, упражнения и повторение ошибок.

## Что есть в MVP

- `Starter: Letters & Sounds` — английский алфавит, названия букв и первые звуки;
- короткие гласные `a / e / i / o / u` на простых словах;
- буквосочетания `sh / ch / th / ee / oo / ar / or`;
- визуальные карточки со встроенными SVG-иллюстрациями и эмодзи;
- произношение слов через Web Speech API;
- короткая тренировка чтения;
- школьные темы `Hello!` и `My Family`;
- сохранение прогресса в `localStorage`;
- список ошибок для повторения;
- адаптивный интерфейс для компьютера и телефона.

## Принципы интерфейса

- крупный читаемый текст;
- спокойная палитра без лишней анимации;
- иллюстрации помогают понять слово, но не отвлекают от задания;
- один экран решает одну учебную задачу;
- сначала пример и звучание, затем тренировка.

## Запуск

```bash
npm install
npm run dev
```

Откройте порт `3000` в браузере. В GitHub Codespaces порт можно открыть через вкладку **PORTS**.

## Статус

Проект находится на этапе MVP. Следующие приоритеты: расширение Starter до последовательных мини-уроков, больше упражнений на слух и чтение, затем остальные темы школьной программы 2 класса.

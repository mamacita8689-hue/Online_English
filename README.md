# Online English

Учебное приложение для русскоязычного ребёнка, изучающего английский язык во 2 классе.

## Цель

Помочь ребёнку понять и закрепить школьную программу английского языка через короткие уроки, упражнения, понятные объяснения на русском языке и повторение ошибок.

## Принципы

- один урок занимает примерно 5–10 минут;
- объяснения короткие и понятные ребёнку;
- сначала пример и смысл, затем правило;
- каждое неправильное действие получает объяснение;
- ошибки сохраняются для повторения;
- контент отделён от интерфейса приложения.

## Структура контента

```text
Unit
└── Lesson
    ├── Vocabulary
    ├── Theory
    └── Exercises
```

Типы данных находятся в `src/content/types.ts`, а учебные модули — в `src/content/units/`.

## Первый модуль

`Unit 01 — Hello!`

Ребёнок учится:

- здороваться и прощаться;
- представляться;
- спрашивать имя;
- спрашивать «Как дела?» и отвечать;
- использовать базовые конструкции `I am`, `You are`, `My name is`.

## Статус

Проект находится на этапе MVP. Первый приоритет — качественный учебный контент 2 класса и движок упражнений. AI-функции можно добавлять после базовой версии.
